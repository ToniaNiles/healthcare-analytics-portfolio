# Healthcare Analytics Portfolio

A portfolio of healthcare analytics projects developed using NHS primary care appointment data.

The aim of this portfolio is to demonstrate practical healthcare analytics skills, including exploratory data analysis, KPI development, operational performance analysis, workforce analytics, forecasting, benchmarking, and dashboard development.

---

## Tools and Technologies

* Python
* pandas
* NumPy
* matplotlib
* Jupyter Notebook
* Power BI 
* Git & GitHub

---

## Portfolio Projects

### Project 1: GP Operational Analysis

Exploration of NHS primary care operational activity, including appointment delivery methods, workforce utilisation, appointment outcomes, access to care, and temporal demand patterns.

**Skills demonstrated**

* Exploratory Data Analysis (EDA)
* Healthcare operations analysis
* KPI development
* Trend analysis
* Data visualisation

---

### Project 2: DNA (Did Not Attend) Analysis

Investigation of factors associated with missed appointments, including waiting times, appointment modes, healthcare professional types, and seasonal variation.

**Skills demonstrated**

* Behavioural analytics
* Segmentation analysis
* KPI analysis
* Time-series analysis
* Healthcare interpretation

---

### Project 3: Workforce Analysis

Analysis of multidisciplinary workforce utilisation across NHS primary care services.

**Skills demonstrated**

* Workforce analytics
* Operational modelling
* Capacity analysis

---

### Project 4: Demand Forecasting

Forecasting future appointment demand using time-series modelling techniques.

**Skills demonstrated**

* Forecasting
* Predictive analytics
* Time-series modelling
* Exponential Smoothing
* Healthcare analytics
* Capacity planning
* Data visualisation

---

### Project 5: Access & Waiting Times Analysis

Analysis of how quickly patients accessed NHS primary care appointments, focusing on same-day and next-day access, waiting time categories, appointment modes, healthcare professional types, and monthly access patterns.

**Skills demonstrated**

* Access analysis
* Waiting time analysis
* KPI development
* Healthcare operations analysis
* Comparative analysis
* Data visualisation

---

### Project 6: Primary Care Performance Dashboard

Development of an interactive Power BI dashboard to monitor NHS primary care performance through executive KPIs, appointment demand, DNA analysis, workforce utilisation, and access to care.

**Skills demonstrated**

* Power BI
* Dashboard development
* DAX measures
* KPI reporting
* Interactive data visualisation
* Healthcare performance monitoring
* Stakeholder communication
