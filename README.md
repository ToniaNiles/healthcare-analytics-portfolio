# Healthcare Analytics Portfolio

A portfolio of healthcare analytics projects developed using NHS primary care appointment data.

The aim of this portfolio is to demonstrate practical healthcare analytics skills, including exploratory data analysis, KPI development, operational performance analysis, workforce analytics, forecasting, benchmarking, and dashboard development.

---

## Tools and Technologies

* Python
* pandas
* NumPy
* matplotlib
* Jupyter Notebook
* Power BI (planned)
* Git & GitHub

---

## Portfolio Projects

### Project 1: GP Operational Analysis

Exploration of NHS primary care operational activity, including appointment delivery methods, workforce utilisation, appointment outcomes, access to care, and temporal demand patterns.

**Skills demonstrated**

* Exploratory Data Analysis (EDA)
* Healthcare operations analysis
* KPI development
* Trend analysis
* Data visualisation

---

### Project 2: DNA (Did Not Attend) Analysis

Investigation of factors associated with missed appointments, including waiting times, appointment modes, healthcare professional types, and seasonal variation.

**Skills demonstrated**

* Behavioural analytics
* Segmentation analysis
* KPI analysis
* Time-series analysis
* Healthcare interpretation

---

### Project 3: Workforce Analysis *(In Progress)*

Analysis of multidisciplinary workforce utilisation across NHS primary care services.

**Planned skills**

* Workforce analytics
* Operational modelling
* Capacity analysis

---

### Project 4: Demand Forecasting *(Planned)*

Forecasting future appointment demand using time-series modelling techniques.

**Planned skills**

* Forecasting
* Predictive analytics
* ARIMA
* Prophet
* Time-series modelling

---

### Project 5: Regional Benchmarking *(Planned)*

Comparison of NHS regions to identify variation in demand, access, and appointment delivery.

**Planned skills**

* Benchmarking
* Comparative analytics
* Health systems analysis

---

### Project 6: Operational Dashboard *(Planned)*

Interactive dashboard for monitoring NHS primary care performance indicators.

**Planned skills**

* Power BI
* Dashboard design
* KPI reporting
* Stakeholder communication
