# Primary Care Performance Dashboard



## Project Overview



This project presents an interactive Power BI dashboard developed using NHS primary care appointment data. The dashboard provides a comprehensive overview of healthcare service performance through executive KPIs, operational trends, workforce utilisation, patient access, and appointment outcomes.



The aim is to demonstrate how Power BI can transform healthcare data into actionable insights for operational monitoring and decision-making.



---



## Dashboard Pages



### 1. Executive Overview



Provides a high-level summary of primary care performance using key performance indicators, including:



- Total Appointments

- Rapid Access Rate

- DNA Rate

- GP Share

- Monthly Appointment Demand



---



### 2. Appointment Demand



Analyses appointment demand across the reporting period through:



- Monthly appointment volume

- Appointments by appointment mode

- Demand trends over time



---



### 3. DNA Analysis



Examines missed appointments by analysing:



- DNA Appointments

- DNA Rate

- Appointment mode

- Healthcare professional type



---



### 4. Workforce Utilisation



Explores workforce contribution across NHS primary care by presenting:



- GP Share

- GP Appointments

- Other Practice Staff Share

- Appointment distribution by healthcare professional type

- Appointment mode by healthcare professional type



---



### 5. Access \& Waiting Times



Evaluates patient access to care through:



- Rapid Access Appointments

- Rapid Access Rate

- Rapid Access Rate by appointment mode

- Rapid Access Rate by healthcare professional type



---
