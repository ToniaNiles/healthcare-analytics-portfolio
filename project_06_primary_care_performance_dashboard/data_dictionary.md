# Data Dictionary



This document describes the key fields used in the NHS Primary Care Appointment dataset.



| Column | Description |

|---------|-------------|

| APPOINTMENT\_MONTH | Month in which the appointment took place. |

| COUNT\_OF\_APPOINTMENTS | Total number of appointments represented by each record. |

| APPT\_STATUS | Appointment outcome (e.g., Attended, DNA, Unknown). |

| APPT\_MODE | Method used to deliver the appointment (Face-to-Face, Telephone, Video/Online, Home Visit). |

| HCP\_TYPE | Healthcare professional responsible for delivering the appointment (GP, Other Practice Staff, Unknown). |

| TIME\_BETWEEN\_BOOK\_AND\_APPT | Waiting time between booking and appointment (e.g., Same Day, Next Day, 2–7 Days). |
